# Contributing to next-content 🤝

First off, thank you for considering contributing to `next-content`! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

Whether you're fixing a bug, adding a new feature, or improving the documentation, your help is welcome!

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub. When filing an issue, make sure to answer these five questions:

1. What version of `next-content` are you using?
2. What operating system and Node.js version are you on?
3. What did you do?
4. What did you expect to see?
5. What did you see instead?

### Suggesting Enhancements
If you have an idea to make `next-content` even better, we want to hear about it! Please open an issue to discuss your proposed changes before writing any code.

### Pull Requests
Ready to contribute some code? Awesome! Here is the process:

1. **Fork the repo** and create your branch from `main`.
2. **Install dependencies:** Run `npm install` (or your preferred package manager).
3. **Make your changes:** Write your code, add comments, and please include tests if applicable.
4. **Run tests:** Ensure everything is still working perfectly by running `npm run test`.
5. **Typecheck and Build:** Ensure the project builds successfully (`npm run build`).
6. **Commit:** Write a clear, descriptive commit message.
7. **Submit a PR:** Push to your fork and submit a pull request!

## Development Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/sshuvoo/next-content.git
   cd next-content
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run tests in watch mode:
   ```bash
   npm run test -- --watch
   ```

## Code Style

- We use **TypeScript**. Please ensure all your code is fully typed.
- We use **Prettier** for formatting. It should run automatically, but you can always check your code style.
